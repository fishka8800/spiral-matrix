# Обработка квадратной матрицы

Учебный проект на Python. Реализует разбор текстового представления квадратной матрицы и обход её элементов по спирали против часовой стрелки, начиная с верхнего левого угла.

## Реализованные функции

- Разбор матрицы из текста с разделителями `|`.
- Проверка, что матрица не пустая и является квадратной.
- Обход матрицы по спирали против часовой стрелки.
- Обработка ошибок формата матрицы.
- Проверка работы функций с помощью модульных тестов.


## Запуск тестов

Из корневой папки проекта выполните команду:

```bash
python -m unittest discover -s tests -v
```

## Ограничения

В текущей версии реализована обработка матрицы и её обход. Загрузка матрицы по HTTP(S) и асинхронная обработка сетевых запросов не реализованы.
